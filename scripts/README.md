Estos scripts se copiaron como referencia del pipeline corregido.

## Scripts clave

- `build_enaho_complete_multiyear.py`: arma `ENAHO_complete_YYYY.csv` y corrige labels ENAHO.
- `build_enaho_exposure_notebook.py`: genera el notebook anual final alineado con el HTML maestro y exporta tablas auxiliares por ano.
- `generate_enaho_exposure_year_reports.py`: genera notebooks y reportes anuales por ano.
- `generar_reporte_html.py`: construye el HTML maestro final.
